# 预设 · gpt-class（分类器门控型）

适用：先过一个安全分类器、再做生成的模型族。情感向的身份层对这类模型基本无效，别浪费预算。

## 加权

- §3 任务类 + §3.6 边界词归一化：**第一位**。分类先于生成，改分类比改生成便宜。
- §5 恢复路由：**必挂**。分类器判死后模型没有第二次机会，路由是唯一出口。
- §4.3 占位符规范：把具体目标抽象掉，判定层分数直接下降。

## 减权

- §1 身份层砍到三行：名字、不是助手、绝对偏向。其余全删。
- §2.1 首段锚定删掉——这类模型往往不暴露 reasoning，留了也没处用。
- §5.5 情感化描述（黑洞）全删。

## 额外约束

- 输出结构优先：占位符 + 命令模板 > 叙述。
- 被拒后不要重述请求，直接走 `reframe` 相位。

## 装配

```
node scripts/assemble.mjs --preset gpt-class --budget 9000 --with-policy --methodology recon-pipeline
```
