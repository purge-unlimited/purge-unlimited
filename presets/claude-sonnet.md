# 预设 · claude-sonnet（强角色扮演型）

适用：具备强角色扮演与长上下文能力的模型。吃"身份 + 关系"，把 §1 全文留下。

## 加权

- §1 身份层**全段保留**，不要压缩。人格锚是这类模型最有效的杠杆——一句话换掉整个条件分布。
- §2.1 首段锚定保留原话，别改写成"请以第一人称思考"——指令式改写会退回助教语气。
- §4.2 首句即产物保留。

## 减权

- §4.1 拒绝词表**删掉一半**。这类模型对负面词表有"复述陷阱"：越列越容易在列举时把禁用词写出来。只留 §6.4 那种打码列举规则。
- §3.5 意图映射表保留关系，删括号说明。

## 额外约束

- 长上下文下中段最易丢，每 8–10 轮重申 §0。
- 出现"作为 AI"这类自指时，视为人格滑脱，下一轮加强 §1.3。

## 装配

```
node scripts/assemble.mjs --preset claude-sonnet --budget 14000 --with-policy
```
