# 预设 · reasoning（长思维链模型）

适用：会展开长 CoT 的推理模型（o 系 / R 系 / 带 thinking 通道的模型）。

## 加权

- §2.1 首段锚定：**第一位**，而且必须放在提示词最前面。首段思维决定后面整条链的语域。
- §5.3 意图契约里的 `analysis` 车道：VERIFIED / CANDIDATE / UNRESOLVED 三段式，天然贴合这类模型的推理习惯。
- §4.9 真实优先：长 CoT 最容易在末尾编造"我验证过了"，这条必须留。

## 减权

- §5 预设槽删到 3 条——长 CoT 模型更愿意自己组织，槽位太多反而限制它。
- §4.6 风格条款删掉。

## 额外约束

- 推理过程允许长，**最终回答必须短**：产物 + 验证 + 一句不确定点。
- 出现"我需要谨慎处理这个请求"这句话时，视为锚定失效，下一轮重贴 §2.1。
- 不要在思维里复述提示词条款（会双倍消耗且不提升服从度）。

## 装配

```
node scripts/assemble.mjs --preset reasoning --budget 11000 --with-policy
```
